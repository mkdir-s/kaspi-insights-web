# Kaspi Insights Web

Красивое локальное веб-приложение для анализа официальных PDF-выписок Kaspi Gold. Пользователь перетаскивает PDF в браузер и получает интерактивный финансовый дашборд без загрузки файла на сервер.

**Публичная версия:** [mkdir-s.github.io/kaspi-insights-web](https://mkdir-s.github.io/kaspi-insights-web/)

## Возможности

- чтение таблиц операций непосредственно из PDF;
- контрольная сверка с краткой сводкой Kaspi;
- поступления, расходы, чистый денежный поток и изменение баланса;
- покупки по категориям, месяцам и дням недели;
- средний чек, средний расход в активный день и доля нераспознанных покупок;
- входящие и исходящие переводы с рейтингом контрагентов;
- количество и сумма полученных переводов по каждому месяцу;
- переводы между своими счетами, снятия наличных, комиссии и возвраты;
- популярные продавцы и концентрация расходов;
- повторяющиеся платежи и статистически необычные крупные покупки;
- полный журнал операций с поиском и фильтрами;
- выгрузка автономного HTML-отчёта;
- сохранение страницы в PDF через стандартный диалог печати;
- экспорт всех операций в CSV для Excel или Google Sheets.

## Приватность

PDF разбирается библиотекой PDF.js внутри браузера. Приложение:

- не отправляет выписку на сервер;
- не сохраняет файл или операции в базе данных;
- не использует сторонние API аналитики;
- очищает данные после обновления или закрытия страницы.

Экспортированные HTML, PDF и CSV содержат финансовые данные — храните их так же внимательно, как исходную выписку.

## Требования

- Node.js 22.13 или новее;
- npm;
- современный Chrome, Edge, Safari или Firefox.

Проверить версию Node.js:

```bash
node --version
```

Если активен старый Node.js, команды проекта автоматически попробуют использовать совместимую версию из Codex или `nvm`. При необходимости путь можно указать вручную:

```bash
KASPI_NODE=/путь/к/node npm run dev
```

На macOS актуальную версию можно установить через Homebrew:

```bash
brew install node@22
```

## Первый запуск

Откройте Terminal и перейдите в папку приложения:

```bash
cd kaspi-insights-web
```

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm run dev
```

Откройте адрес, показанный в терминале. Обычно это:

```text
http://localhost:3000
```

## Как пользоваться

1. В приложении нажмите на область загрузки или перетащите в неё официальный PDF Kaspi Gold.
2. Подождите, пока индикатор дойдёт до 100%. Для большой выписки это может занять несколько секунд.
3. Убедитесь, что справа вверху отображается статус «Данные сошлись».
4. Изучайте разделы «Обзор», «Расходы», «Переводы» и «Операции».
5. Используйте поиск и фильтры в журнале операций.
6. Для нового файла нажмите «Другая выписка».

### Что означает проверка

Приложение независимо суммирует все строки и сравнивает их со сводкой Kaspi:

- начальный остаток + операции = конечный остаток;
- пополнения;
- поступления со своих счетов;
- переводы;
- переводы на свои счета;
- покупки;
- снятия наличных;
- операции «Разное».

Если хотя бы одна проверка не прошла, не полагайтесь на итоговые показатели до проверки исходного PDF.

## Экспорт отчёта

Нажмите «Выгрузить отчёт» в правом верхнем углу.

### Красивый HTML-отчёт

Создаёт один автономный `.html`-файл с ключевыми метриками, таблицами и контрольной сверкой. Его можно открыть в браузере без запущенного приложения.

### Сохранить в PDF

Открывает стандартный диалог печати браузера. Выберите «Сохранить как PDF». Для лучшего результата включите печать фоновой графики.

### Все операции CSV

Экспортирует журнал операций в UTF-8 с разделителем `;`. Файл подходит для русской локали Excel. Если Excel открыл данные в одной колонке, импортируйте файл через «Данные → Из текста/CSV» и выберите разделитель `;`.

## Поддерживаемый формат

Поддерживается официальная текстовая выписка Kaspi Gold с таблицей:

```text
Дата | Сумма | Операция | Детали
```

Сканированные документы без текстового слоя и выписки других банков не поддерживаются. Для них потребуется отдельный OCR-парсер.

## Категоризация

В выписке нет MCC-кода, поэтому категории назначаются по названию продавца. Правила находятся в массиве `categoryRules` файла `lib/kaspi.ts`.

Чтобы добавить продавца:

```ts
["Продукты", ["MAGNUM", "GALMART", "НОВЫЙ МАГАЗИН"]]
```

Регистр не важен. Если продавец подходит нескольким категориям, используется первое правило сверху.

## Возможные проблемы

### В PDF не найдена таблица операций

Убедитесь, что это оригинальная выписка Kaspi Gold, а не скриншот и не результат печати страницы в PDF.

### Данные не сошлись

Скачайте выписку повторно и не редактируйте её перед загрузкой. Проверьте, что файл полностью загрузился и содержит весь выбранный период.

### Графики отображаются пустыми

Обновите браузер до актуальной версии и отключите расширения, блокирующие выполнение локального JavaScript.

### Порт 3000 занят

Запустите приложение на другом порту:

```bash
npm run dev -- --port 3001
```
